# ร้านเช็กสต๊อก - Phase 1

โปรเจกต์ Next.js สำหรับ Phase 1:
- หน้าเว็บภาษาไทย
- ใช้ mock data ชั่วคราว
- ยังไม่เชื่อม MongoDB
- ยังไม่ทำ Google Login
- มี layout หลัก, เมนูหลัก, หน้า Dashboard, ร้าน / สาขา, หมวดหมู่สินค้า, รายการสินค้า, เช็กสต๊อก, รายการต้องซื้อ, ประวัติ
- มีปุ่มพิมพ์และ print layout สำหรับ A4

## วิธีรันในเครื่อง

1. ติดตั้ง dependencies
```bash
npm install
```

2. เปิดโหมดพัฒนา
```bash
npm run dev
```

3. เปิดเว็บที่
```bash
http://localhost:3000
```

## ฟังก์ชันพิมพ์

ไปที่หน้า `รายการต้องซื้อ` แล้วใช้ปุ่ม:
- พิมพ์รายการทั้งหมด
- พิมพ์เฉพาะรายการที่ต้องซื้อ
- พิมพ์เฉพาะรายการที่ยังไม่ได้ซื้อ

ตอนพิมพ์ระบบจะซ่อนเมนูและปุ่มต่าง ๆ และใช้ layout สำหรับกระดาษ A4

## Phase ต่อไปที่ควรทำ

1. เชื่อม MongoDB และสร้าง schema จริง
2. ทำ Google Login และกำหนดสิทธิ์ผู้ใช้
3. ทำ CRUD จริงสำหรับสินค้า, หมวดหมู่, สาขา
4. ทำ filter, search, และ pagination
5. ทำ export / import ข้อมูล และปรับหน้าพิมพ์ให้ละเอียดขึ้น
